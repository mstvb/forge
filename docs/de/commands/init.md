# init

Initialisiert ein neues Forge-Repository im aktuellen Verzeichnis.

## Synopsis
```
forge init
```

## Beschreibung
Erstellt ein `.forge`-Verzeichnis mit `objects/`, `commits/`, einer leeren `HEAD` und einem leeren `index`. Wenn bereits ein Repository vorhanden ist, wird eine Meldung angezeigt und nichts geändert.

## Beispiele
```
PS C:\path\to\project> forge init
[Forge] >> Repository erfolgreich initialisiert
```
