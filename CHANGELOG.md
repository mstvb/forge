## Added

- `add` has added

  > Add Files to Repository

  > Options
  
    - `--all` All Data Added

- `back` has added

  > Restore to last Snapshot (Commit)

- `commit` has added

  > Commit Version


- `diff` has added

  > Show Difference

- `init` has added

  > Initialize Version Control

- `log` has added

  > List History

- `pull` has added

  > Copy Repository from other Storage

- `push` has added

  > Copy Repository in new Destination

- `restore` has added

  > Restore Files

  > Options

    - `--all` All Indexed Files restored

- `rm` has added

  > Remove Files

  > Options

    - `--cached` Remove from Index not from Disk

- `show` has added

  > Display Content

  > Options

    - `--object` Show Content of Object with Hash
    - `--path` Show Content of Object with Path

- `status` has added

  > List [ Staged | Changed | Deleted | Unused ]

- `tag` has added

  > Manage Tags

  > Options

    - `--delete` Delete a Tag
    - `--list` List all Tags

- `branch` has added

  > Manage Branches

  > Options

    - `--create` Create a Branch
    - `--delete` Delete a Branch
    - `--checkout` Switch to Branch
    - `--list` List all Branches

- `reset` has added

  > Reset Forge

  > Options

    - `--yes` Submit Reset
    - `--dry-run` Show Deleted Files
    - `--backup-dir` Directory for Forge Backup
